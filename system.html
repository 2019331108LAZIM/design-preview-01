“A print is a conversation held twice.”
Inter
Body · UI · navigation · card titles · labels · metadata

Body copy sits at 16px with 1.6 leading and normal tracking. Uppercase labels are 11px minimum, 600 weight, tracked .14–.18em. Everything a reader reads or operates is set in Inter; the display serif is reserved for headings, section titles and pull quotes at 24px and above, where its high stroke contrast is an asset rather than a legibility cost.

Text hierarchy

Primary — --ink

Body copy — --ink2, 82% of the primary ink

Supporting / metadata — --ink3, 66%

Both steps clear WCAG AA against base and panel grounds in either mode. Light-on-dark type reads optically thinner than its contrast ratio implies, so the dark mode carries the same values rather than sitting lower.
